# House Search

A simple React + Vite app that lets users browse house listings by location. Clicking a location shows the houses available in that area, using data from the local JSON file.

## Features

- View a list of locations
- Open a location to see matching houses
- See each house card with price, bedroom/bathroom details, and availability

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
